# model-bench

Daily notes on the cheap models served by **opencode-go** — what they cost, how
fast they were, and what (if anything) they got wrong.

Written in very simple words, in **English and Hinglish** (use the globe button
in the top bar). Light and dark themes included.

- Blog: https://nd28.github.io/model-bench/
- How the bench is run and how a post is written: [`AGENTS.md`](AGENTS.md)

It is a smoke check, not a leaderboard. The jobs are small on purpose, and every
number comes from a single run.
